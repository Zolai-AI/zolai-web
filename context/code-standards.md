# Code Standards — Zolai Web

- **Languages:** TypeScript/Next.js, Hono, Prisma, Tailwind.
- TypeScript strict mode; Prettier + ESLint; Conventional Commits.
- Keep secrets in `.env` (enforced by push protection); never commit tokens.
- Components under `components/`, pages under `app/`.
- Tests via Vitest; lint via ESLint.
